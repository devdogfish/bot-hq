# Sounds

The iMessage-style set (`imessage/`) plays on send, receive and tapback. Each sound comes as AAC (`.m4a`)
with an MP3 fallback, 64 kbps mono, peak-normalized to −6 dBFS, with leading silence trimmed and a short
fade-out. The app plays them at volume 0.35.

| File | Source | Author | Trim |
|---|---|---|---|
| `send` | [Message Sent Swoosh](https://pixabay.com/sound-effects/technology-message-sent-swoosh-638351/) | Chisper | 0.40 s |
| `receive` | [Message Ping](https://pixabay.com/sound-effects/film-special-effects-message-ping-351298/) | Universfield | 0.62 s |
| `reaction` | [soft subtle ui pop sfx](https://pixabay.com/sound-effects/film-special-effects-soft-subtle-ui-pop-sfx-348820/) | abhicreates | 0.19 s |
